# Road Lane Detection and Departure Warning

## Problem Statement
Detect road lane markings from road images and identify when a vehicle appears to move outside the detected lane.

## Objectives
- Detect lane markings using computer vision.
- Apply image preprocessing and edge detection.
- Detect lane lines using the Hough Transform.
- Display detected lanes on road images.

## Methodology
1. Load a road image.
2. Convert the image to grayscale.
3. Apply Gaussian blur.
4. Detect edges using Canny edge detection.
5. Select the road region of interest.
6. Detect lines using the Hough Transform.
7. Draw the detected lane lines.
