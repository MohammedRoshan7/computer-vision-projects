# Traffic Sign Recognition Using CNN

## Problem Statement
Traffic signs communicate road rules and warnings. This project uses
deep learning to classify traffic sign images into their corresponding categories.

## Objectives
- Classify traffic sign images.
- Train a Convolutional Neural Network (CNN).
- Evaluate model performance.
- Save prediction results and evaluation metrics.

## Dataset
German Traffic Sign Recognition Benchmark (GTSRB).

Official dataset website:
https://benchmark.ini.rub.de/gtsrb_dataset.html

## Methodology
1. Load the dataset.
2. Resize images to 32 x 32 pixels.
3. Normalize image values.
4. Split data into training and validation sets.
5. Train a CNN classifier.
6. Evaluate the model.
7. Save the trained model and evaluation report.

## Tools
Python, TensorFlow/Keras, OpenCV, NumPy, pandas, scikit-learn, Google Colab.

## Results
See the results folder for evaluation metrics and the trained model.

## Limitation
This project classifies traffic sign images. It does not locate signs
automatically in a complete road scene.

## Conclusion
The project demonstrates traffic sign classification using a CNN.
